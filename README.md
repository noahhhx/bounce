# Bounce

Self-hosted, whole-home audio broadcasting. Cast music from your phone or
desktop to a single server on your LAN, and Bounce broadcasts
synchronized audio to small players wired to speakers in every room.

## Documentation

Setup guides and feature docs are at
<https://noahhhx.github.io/bounce/>. To preview them locally, run
`mkdocs serve` in the devenv shell. The shell installs MkDocs from
`docs/requirements.txt`.
