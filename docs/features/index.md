# Features

These pages explain what Bounce does and how to use each feature. Until the
web UI exists, you use most features through the [HTTP API](../reference/http-api.md).
The examples use `curl` and assume the server answers at
`http://localhost:7701`.

- [Spotify Connect](spotify.md) lets you cast from the Spotify app.
- [Zones](zones.md) group speakers into rooms and pick what each room plays.
- [Volume](volume.md) sets how loud each room and each source plays.
- [Multi-room sync](sync.md) keeps every room on the same source in time.
- [Speaker logs](logs.md) let you read a speaker's logs from the server.
- [Web UI](web-ui.md) is not available yet.
- [Speaker updates](updates.md) are not available yet.
